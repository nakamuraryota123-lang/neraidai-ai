# 狙い台AI v0.3

キクヤ堺本店「L真打吉宗」向けの、スマホ対応・インストール可能なWebアプリです。Version 1は静的ファイルだけで動き、記録は端末内と任意のGoogle Drive `appDataFolder` に保存します。

## Version 1

- 手入力、日付・ホール・機種・配置番号・台番号管理
- 差枚グラフ、履歴、説明付きAIスコアランキング
- OpenAI Visionによるスクリーンショット入力
- Google Drive同期、JSONバックアップ、PWA・オフライン対応
- 初期ホール: キクヤ堺本店 / 初期機種: L真打吉宗

> AIスコアは現時点では説明可能なヒューリスティックです。的中を保証せず、遊技判断は利用者自身で行ってください。

## 起動

Service Workerを使うため、ファイルを直接開かずHTTPサーバーで配信します。

```bash
python -m http.server 8080
```

`http://localhost:8080` を開きます。GitHub Pagesにもそのまま配置できます。

## 外部サービス設定

### スクショAI

アプリの「設定」にOpenAI APIキーを入力します。キーはブラウザのlocalStorageだけに保存されます。本番運用では、キーを端末に置かないサーバー側プロキシへ移行してください。

### Google Drive

Google Cloud ConsoleでWeb OAuthクライアントを作成し、利用元URLを「承認済みのJavaScript生成元」に登録します。Drive APIを有効化し、クライアントIDをアプリの設定へ入力してください。アプリ専用領域のみを扱う `drive.appdata` スコープです。

## 拡張ロードマップ

- **Version 2:** マスタ編集UI、CSV一括取込、配置変更履歴、画像読取レビュー、期間・曜日フィルター、重複解決
- **Version 3:** サーバー側AI、学習モデルとバックテスト、複数ユーザー、通知、信頼区間、ホール・機種追加テンプレート

データは `hall`、`machine`、`position`（配置上の固定識別子）、`unit`（変更され得る台番号）を別フィールドで保持するため、機種やホールの追加と台番号変更に対応できます。
